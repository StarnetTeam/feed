# مراقب فيدات الأقمار من روابط Facebook العامة

يعمل المشروع داخل GitHub Actions كزائر مجهول، بدون تسجيل دخول Facebook وبدون GitHub Secrets. عند بدء Workflow، يفتح الجروبات الثلاثة **فورًا وبالتتابع**: الأول ثم الثاني ثم الثالث، ولا يفتحها في نفس الوقت.

## ما الذي يقرأه كل تشغيل؟

- يبدأ الجمع مباشرة؛ لا يوجد انتظار عشوائي قبل أول جروب.
- ينتظر 5 ثوانٍ فقط بين الجروبات لتجنب إرسال الطلبات دفعة واحدة.
- يفتح ترتيب المنشورات الزمني إن كان Facebook يدعم ذلك عبر `sorting_setting=CHRONOLOGICAL`.
- لا يعمل تمرير للصفحة ولا يحمّل الصور.
- يفحص أول 20 بطاقة منشور ظاهرة لكل جروب.
- يحاول التقاط فيدات المنشورات الحديثة، ويفضل ما يحمل `Today` أو `منذ ساعات` أو وقتًا نسبيًا.
- إذا أخفى Facebook التوقيت من النص، يقبل بطاقة حديثة ظاهرة فقط عندما تحتوي على نمط تردد وشفرة معًا.
- يسجل النتائج الجديدة في `data/fids.json` مع وسم `collection_window: last_12_hours`.

بهذا يمكنه التقاط فيدين أو ثلاثة في نفس اليوم ومن أكثر من جروب، بدل الاعتماد على وجود كلمة `اليوم` حرفيًا فقط.

## الجدولة

الإعداد الحالي يشغّل الفحص 6 مرات يوميًا بتوقيت UTC:

```text
12:00، 14:00، 16:00، 18:00، 20:00، 22:00
```

ويجب تحويل مواعيد المباريات إلى UTC قبل تعديل `.github/workflows/collect.yml`. التشغيل اليدوي يبدأ فورًا ولا ينتظر موعد الجدولة.

## لماذا قد لا يظهر أي فيد؟

إذا كانت سجلات Workflow تقول `Candidates from group: 0`، فغالبًا أحد الأمور التالية صحيح:

1. Facebook يعرض صفحة تسجيل دخول للزائر المجهول.
2. الجروب عام لكن المنشورات لا تظهر في HTML الذي يصل إلى GitHub.
3. Facebook غيّر أسماء أو بنية عناصر المنشورات.
4. المنشور يضع التردد أو الشفرة في صورة فقط؛ هذا الإصدار لا ينفذ OCR على الصور.

إذا ظهرت صفحة تسجيل دخول أو CAPTCHA، لا يحاول المشروع تجاوزها. يلزم عندها مصدر نصي عام بديل أو API مصرح به.

## ملف الروابط TXT

الروابط موجودة في `config/groups.txt`. وبعد رفع المشروع يمكن عرضها من رابط Raw:

```text
https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/config/groups.txt
```

## شكل JSON

```json
{
  "satellite": "Eutelsat 10.0°E (C-Band)",
  "frequency": "3905 V 3750",
  "code": "B0 43 D4 C7 2D 24 D2 23",
  "source": "https://www.facebook.com/groups/351975505940194/",
  "collection_window": "last_12_hours"
}
```

هذا البروتوكول يقلل الضغط باستخدام متصفح واحد، طلبات متسلسلة، فاصل قصير، وعدم التمرير أو الطلبات المتوازية. لكنه لا يضمن عدم ظهور حماية Facebook أو Cloudflare، ولا يتجاوز تسجيل الدخول أو CAPTCHA.
