# مراقب فيدات الأقمار من روابط Facebook العامة

يعمل المشروع داخل GitHub Actions كزائر مجهول، بدون تسجيل دخول Facebook وبدون GitHub Secrets. في كل نافذة زمنية يزور **الجروبات الثلاثة كلها** مرة واحدة بترتيب عشوائي، ويقرأ أحدث المنشورات النصية الظاهرة فقط، ثم يحفظ الفيدات الجديدة الخاصة بتاريخ اليوم في `data/fids.json`.

## الفحص المتكرر حول أوقات المباريات

الإعداد الحالي يشغل الفحص عند الساعات التالية بتوقيت UTC:

```text
12:00، 14:00، 16:00، 18:00، 20:00، 22:00
```

ويضيف GitHub Actions تأخيرًا عشوائيًا من 0 إلى 20 دقيقة بعد بداية كل نافذة. عدّل الساعات في `.github/workflows/collect.yml` حسب توقيت المباريات لديك، وعدّل أيضًا `config/match_windows.json` لتوثيق النوافذ والإعدادات.

التأخير الفعلي في Workflow مضبوط حاليًا من 0 إلى 10 دقائق فقط، لأن وقت `sleep` يُحسب ضمن مدة GitHub Actions. تم رفع مهلة المهمة إلى 45 دقيقة حتى تشمل تثبيت Playwright وفحص الجروبات الثلاثة. إذا ظهرت رسالة `The operation was canceled` أثناء `sleep`، حدّث ملفات المستودع ثم أعد تشغيل Workflow؛ غالبًا كانت المحاولة السابقة تجاوزت مهلة 25 دقيقة أو أُلغيَت من GitHub قبل بدء الجمع.

ملاحظة: GitHub Actions يستخدم UTC. إذا كانت مواعيدك بتوقيت القاهرة مثلًا، حوّلها إلى UTC قبل وضعها في `cron`، مع مراعاة التوقيت الصيفي.

## كيف يقلل الضغط على Facebook؟

- جلسة متصفح واحدة فقط.
- لا توجد طلبات متوازية.
- الجروبات تُفحص بترتيب عشوائي.
- يوجد فاصل عشوائي بين كل جروب وآخر، افتراضيًا 45–90 ثانية.
- لا يوجد تمرير للصفحة ولا تحميل للصور.
- يتم فحص أول 8 بطاقات منشورات ظاهرة فقط.
- لا توجد إعادة محاولات سريعة عند فشل الصفحة.

هذا بروتوكول وصول منخفض ومحترم، وليس وسيلة لتجاوز Cloudflare أو CAPTCHA أو حظر Facebook. لا يمكن ضمان عدم ظهور التحقق، لأن القرار يعود إلى Facebook وشبكة GitHub.

## فلترة منشورات اليوم

لا يحفظ البرنامج نتيجة إلا إذا احتوى نص بطاقة المنشور على مؤشر اليوم الحالي، مثل:

- `Today`, `Just now`, `minutes ago`, `hours ago`.
- `اليوم`, `الآن`, `منذ دقائق`, `منذ ساعات`.
- تاريخ اليوم بصيغة رقمية أو باسم الشهر.

هذا يمنع إعادة حفظ فيدات قديمة، مع الاستمرار في التقاط فيدين أو ثلاثة في نفس اليوم ومن أكثر من جروب. كل نتيجة جديدة تُضاف مرة واحدة فقط إلى `data/fids.json` اعتمادًا على بصمة القمر والتردد والشفرة.

## ملف الروابط بصيغة TXT

الروابط موجودة في:

```text
config/groups.txt
```

بعد رفع المشروع إلى GitHub سيكون رابط TXT العام مثل:

```text
https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/config/groups.txt
```

## قيد الوصول العام

هذا الإصدار لا يتجاوز تسجيل الدخول أو CAPTCHA أو Cloudflare أو أي حماية. إذا أعاد Facebook صفحة تسجيل الدخول أو لم يعرض المنشورات للزائر المجهول، فلن يستطيع GitHub Actions استخراجها دون مصدر عام بديل أو API مصرح به.
