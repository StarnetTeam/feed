# مراقب فيدات الأقمار من روابط Facebook العامة

يعمل المشروع داخل GitHub Actions كزائر مجهول، بدون تسجيل دخول Facebook وبدون GitHub Secrets. يقرأ روابط الجروبات من ملف TXT داخل المستودع، يفتح كل رابط عام، ثم يستخرج المنشورات التي تحتوي على القمر والتردد وشفرة الفيد ويحفظها في `data/fids.json`.

## ملف الروابط بصيغة TXT

الروابط موجودة في:

```text
config/groups.txt
```

بعد رفع المشروع إلى GitHub سيكون له رابط Raw بهذا الشكل:

```text
https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/config/groups.txt
```

استبدل `USERNAME` و`REPOSITORY` باسم حسابك ومستودعك. هذا الرابط يعرض الروابط كنص TXT ويمكن استخدامه كمصدر خارجي أو تنزيله مباشرة. ويستطيع البرنامج نفسه قراءة الملف من داخل المستودع عند كل تشغيل.

## التثبيت

1. ارفع محتويات المشروع إلى مستودع GitHub عام أو خاص.
2. عدّل `config/groups.txt` وضع رابطًا واحدًا في كل سطر:

```text
https://www.facebook.com/groups/351975505940194/
https://www.facebook.com/groups/1597114337566867/
https://www.facebook.com/groups/2016699558837964/
```

3. لا تحتاج إلى إضافة أي Secret أو كلمة مرور.
4. شغّل Workflow باسم **Collect satellite feeds** يدويًا من تبويب Actions لاختباره.

## الجدولة

الإعداد الحالي يشغل الجامع أربع مرات يوميًا عند 00:00 و06:00 و12:00 و18:00 بتوقيت UTC. لتشغيله ثلاث مرات، عدّل ملف `.github/workflows/collect.yml` مثلًا إلى:

```yaml
- cron: '0 2,10,18 * * *'
```

GitHub Actions يستخدم UTC وقد يتأخر التشغيل قليلًا وقت الضغط.

## شكل JSON

```json
[
  {
    "satellite": "Eutelsat 10.0°E (C-Band)",
    "frequency": "3905 V 3750",
    "code": "B0 43 D4 C7 2D 24 D2 23",
    "source": "https://www.facebook.com/groups/351975505940194/",
    "id": "4f37446f83fc40f2",
    "first_seen_utc": "2026-11-03T00:00:00+00:00"
  }
]
```

## قيد مهم من Facebook

هذا الإصدار لا يحاول تجاوز تسجيل الدخول أو CAPTCHA أو أي حماية. إذا كان الجروب لا يعرض المنشورات للزائر المجهول، أو إذا أعاد Facebook صفحة تسجيل الدخول، فلن يستطيع GitHub Actions استخراج محتواه بدون حساب. يجب أن يكون الجروب والمنشوران ظاهرين للعامة فعلًا في نافذة خاصة/بدون تسجيل دخول.

كذلك قد يحجب Facebook طلبات GitHub أو يغيّر شكل الصفحة؛ عندها لا توجد طريقة مضمونة للعمل بدون مصدر عام بديل مثل RSS أو صفحة ويب عامة أو API مصرح به.
